# TipEase - Tipping Calculator

**TipEase** is a modern, user-friendly tipping calculator application built with Next.js and styled with Tailwind CSS and ShadCN UI components. It provides a seamless experience for calculating tip amounts and splitting bills among multiple people. The interface is designed to be clean, professional, and responsive, ensuring a great user experience on both desktop and mobile devices.

## ✨ Features

-   **Bill Amount Input**: Enter the total bill amount to get started.
-   **Select Tip Percentage**:
    -   Choose from predefined tip percentages (`15%`, `18%`, `20%`, `25%`).
    -   Option to enter a **custom tip percentage** for full flexibility.
-   **Split the Bill**: Specify the number of people to split the bill with, and the app will calculate each person's share.
-   **Round Up Share**: A convenient switch to round up each person's share to the nearest whole dollar, making payments simpler.
-   **Real-time Calculation**: All calculations happen instantly as you input the values.
-   **Detailed Summary**:
    -   Clear breakdown of the `Tip Amount`.
    -   The `Total Bill` including the tip.
    -   A highlighted section showing what **Each Person Pays**.
-   **Responsive Design**: The application is fully responsive and works beautifully on all screen sizes, from mobile phones to desktop computers.
-   **Modern UI/UX**: A minimalistic and professional design that is intuitive and easy to use.

## 🚀 Getting Started

To get this project up and running on your local machine, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm (or yarn) installed on your machine.

-   [Node.js](https://nodejs.org/) (v18 or later recommended)
-   [npm](https://www.npmjs.com/get-npm)

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-repository/tipease.git
    cd tipease
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the application in action.

## 🛠️ Tech Stack

This project is built with a modern and robust tech stack:

-   **[Next.js](https://nextjs.org/)**: A powerful React framework for building server-rendered and static web applications.
