# **App Name**: TipEase

## Core Features:

- Bill Input: Input the bill total and select a tip percentage.
- Split Calculation: Specify the number of people to split the bill with.
- Output Display: Display the tip amount, total bill with tip, and each person's share.
- Round Up: Option to round up each person's share to the nearest dollar.

## Style Guidelines:

- Primary color: Vibrant pink (#F06292) for a modern and playful feel. This choice takes inspiration from the user's request for a vibrant pink and purple color scheme.
- Background color: Soft pink (#F8BBD0) for a calming and cohesive look. This color matches the hue of the primary, and fits the light color scheme.
- Accent color: Purple (#BA68C8) to complement the primary color and add depth.
- Body and headline font: 'PT Sans' (sans-serif) for clear and readable text.
- Use simple, intuitive icons for ease of navigation and visual appeal.
- Clean and intuitive layout for easy input and clear display of results.
